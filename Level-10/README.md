# 🏴‍☠️ Bandit Level 10

> **Goal:** Decode the Base64-encoded contents of `data.txt` to find the password for Level 11.

---

## 🔎 Command Used

```bash
base64 -d data.txt
```

### How it works

- `base64` → Works with Base64-encoded data.
- `-d` → Decodes the encoded data.
- `data.txt` → The file containing the encoded password.

The decoded output reveals the password for **Level 11**.
